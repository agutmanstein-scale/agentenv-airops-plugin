# AirOpsEnv for AgentEnv

An airline operations desk recovers a real storm day at a JetBlue hub: cancel, hold and re-time flights as the FAA's
ground delay programs, ground stops and terminal forecasts arrive, live on AgentEnv's virtual clock, graded against a
proven hindsight optimum. Built from public U.S. records (BTS on-time data, FAA Command Center advisories, archived
METARs and TAFs). Work in progress; see [DESIGN.md](DESIGN.md).
